# 0001: Stack
Status: accepted
Date: 2026-10-05
Deciders: Joao Vitor

## Context
We need one default stack so agents do not each pick their own.

## Decision
TypeScript, Next.js (App Router), deployed on Vercel, pnpm as package manager.

## Consequences
Database, auth, LLM provider and agent framework are still open and need their own records.
