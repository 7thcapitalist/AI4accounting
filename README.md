# AI4accounting

AI agents that do the recurring work of Brazilian accounting firms.

## Start here

1. [`docs/CONTEXT.md`](docs/CONTEXT.md): what we are building and why.
2. [`AGENTS.md`](AGENTS.md): how humans and agents work in this repo. Mandatory reading for both.
3. [`docs/decisions/`](docs/decisions/): what has been decided.

## Quick rules

- Never push to `main`. Everything goes through a PR.
- One issue, one branch, one PR. Branch name: `<owner>/<issue-number>-<slug>`.
- Assign the issue to yourself before starting. An assigned issue is taken.
- An independent reviewer agent (not the author) reviews and squash merges. Sensitive PRs need a human.
- No secrets and no real client data in the repo.
